### 4. Visitor Counter
A shared visitor counter integrated into the portfolio through a serverless API.

- Connects the React frontend to a Vercel serverless function.
- Uses Upstash Redis to persist and increment the shared counter.
- Keeps Redis credentials in server-side environment variables.
- Returns the counter value as JSON for display in the frontend.

**Technologies:** React.js, Node.js, Vercel Functions, Upstash Redis, REST API

**Implementation flow:**

`React Frontend → Vercel API → Upstash Redis → JSON Response`

The current implementation increments the counter for each API request; it does not yet represent unique visitors.

## 💻 Run Locally

### Prerequisites
- Node.js and npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/RudraS52/portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open the local URL shown in your terminal, typically `http://localhost:3000`.

**Note:** Features that depend on hosted APIs require their corresponding endpoints and environment variables to be configured. Never commit API tokens or other secrets to the repository.
